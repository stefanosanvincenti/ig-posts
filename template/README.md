# Template post Instagram (1080x1350)
Render con Playwright/Chromium, viewport 1080x1350, scale 1, poi JPEG qualità ~72.
Palette: bg #0C0818, viola #A855F7, ciano #39E5FF. Barra "browser" in alto, kicker, titolo (parola chiave in viola),
sottotitolo, lista numerata (max 5 voci, quadratini alternati viola/ciano), footer "Salva per dopo" + @stefano_sanvincenti_seo.
Verificare sempre che nessun testo sia tagliato dal footer.

REGOLA: colori e layout cambiano per ogni post in base all'argomento (non riusare sempre viola/ciano). Varianti in template/variants/.
make_story.py accetta colori opzionali: python3 template/make_story.py posts/X.jpg BG_HEX BORDO_HEX SCRITTA_HEX
Contenuti: mai parlare di iscrizione nel 2026 con scadenza nel 2027 (NIS2).
